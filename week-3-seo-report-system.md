## PROMPT 1: Design Your Report Template (Run Once)

```
I run an SEO company serving small businesses in Germany. I need a professional
monthly report template that my clients will actually read and value.

My tools:
- SE Ranking (website audits, keyword tracking, traffic data)
- Local Dominator (local keyword grid tracking)
- Google Business Profile data (if client gives access)

Design a monthly SEO report template with these requirements:

STRUCTURE:
1. Executive Summary (3-4 sentences in plain German - the ONE section
   every client reads)
2. Wins This Month (bullet points of positive changes - clients need
   to feel progress)
3. Keyword Rankings (table showing movement: keyword, position last month,
   position this month, change)
4. Local Search Visibility (Local Dominator grid summary)
5. Website Health (audit score, critical issues fixed, remaining issues)
6. Traffic Overview (visitors, top pages, trends)
7. Competitive Landscape (brief - how they compare to local competitors)
8. Actions Taken This Month (what I actually did for them)
9. Recommended Next Steps (what I plan to do next month)
10. Appendix: Full Data (for clients who want the details)

RULES:
- Every section must start with a one-sentence plain-language summary
- Use green/red arrows or +/- indicators for changes
- No jargon without explanation in parentheses
- The Executive Summary should be something they could forward to
  their business partner and it would make sense
- Include a "health score" (e.g., 72/100) that's easy to track month over month
- Total report: 3-4 pages max (not counting appendix)

Give me:
1. The full template structure with placeholder text
2. Guidance on what data to pull from each tool for each section
3. A sample Executive Summary so I understand the tone
```

## PROMPT 3: Executive Summary Writer

If you want to refine just the Executive Summary (the most important part):

```
Write an Executive Summary in German for a monthly SEO report.

Client: [BUSINESS TYPE] in [CITY]
Month: [MONTH]

Key facts:
- Biggest win: [e.g., "Moved from position 14 to position 6 for 'Zahnarzt München'"]
- Website health: [improved/declined] from [X] to [Y]
- Traffic change: [+/- X%]
- Most important issue: [e.g., "Mobile speed still needs improvement"]
- Main action next month: [e.g., "Focus on building local backlinks"]

Write 3-4 sentences that:
1. Lead with the win (positive framing)
2. Summarize overall progress
3. Acknowledge what still needs work (honest but optimistic)
4. Tease next month's focus (so they look forward to staying)

Tone: confident professional, like a trusted advisor giving a progress update.
Not salesy. Not overly technical.
```

## PROMPT 4: Competitive Comparison Section

Run quarterly or when onboarding a new client.

```
I need to create a competitive SEO comparison for my client's report.

My client:
- Business: [NAME]
- Website: [URL]
- City: [CITY]
- Type: [BUSINESS TYPE]

Top 3 local competitors (from Google search results):
1. [COMPETITOR NAME] - [URL]
2. [COMPETITOR NAME] - [URL]
3. [COMPETITOR NAME] - [URL]

SE Ranking data for each:
- My client: Health score [X], Domain authority [X], Keywords ranking [X]
- Competitor 1: Health score [X], Domain authority [X], Keywords ranking [X]
- Competitor 2: Health score [X], Domain authority [X], Keywords ranking [X]
- Competitor 3: Health score [X], Domain authority [X], Keywords ranking [X]

Create a competitive comparison section that:
1. Shows where my client stands vs competitors (table format)
2. Identifies specific gaps (what competitors do that my client doesn't)
3. Highlights advantages my client has (anything they do better)
4. Gives 3 specific recommendations to close the gap
5. Estimates realistic timeline for improvement

Write in German. Frame it motivationally - "here's where you are, here's
the gap, here's how we close it" - not "you're losing."
```

## Data Collection Checklist

Run through this checklist on the same day each month (e.g., last Friday).

### From SE Ranking:
- [ ] Export keyword rankings (current vs. previous month)
- [ ] Run fresh website audit
- [ ] Screenshot the audit score comparison (this month vs. last)
- [ ] Export traffic data (organic sessions, top pages)
- [ ] Note critical errors count (fixed vs. new)
- [ ] Check backlink profile changes
- [ ] Run competitor comparison

### From Local Dominator:
- [ ] Screenshot keyword grids for all tracked keywords
- [ ] Note average position changes
- [ ] Identify best and worst performing keywords
- [ ] Compare to previous month's grids

### From Google Business Profile (if you have access):
- [ ] Profile views
- [ ] Search appearances
- [ ] Website clicks from profile
- [ ] Direction requests
- [ ] Phone calls
- [ ] Review count and average rating change

### From Your Own Records:
- [ ] List all SEO actions taken this month
- [ ] List all issues fixed
- [ ] Note any client communications or special requests
- [ ] Plan next month's priorities

## Report Format Options

**Option A: Google Docs (recommended for starting out)**
- Create a template doc with your branding (logo, colors, fonts)
- Duplicate it each month
- Paste Claude's output into the sections
- Export as PDF to send to client

**Option B: Canva (for more professional look)**
- Use a report template
- Drop in your data and Claude's text
- More visual but takes more time

**Option C: Google Slides (good middle ground)**
- One slide per section
- Clean, visual, easy to update monthly
- Present in calls, send as PDF afterward

Start with Google Docs. Move to Slides or Canva when you have 3+ clients
and the investment in design pays off.
